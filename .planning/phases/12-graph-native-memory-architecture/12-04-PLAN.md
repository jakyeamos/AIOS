# Plan 12-04: Cache-Aware Context Compiler

## Objective

Implement `services/context_compiler.py`, the module that assembles the full prompt for agent execution in a cache-aware, stable-prefix-first layout. This module wraps `MemoryCompiler` and controls the ordering of all context sections.

## Scope

- Implement `ContextCompiler` with a `compile()` method
- Enforce stable-first, dynamic-last section ordering
- Implement token budget enforcement, deduplication, and staleness filtering
- Remain provider-agnostic (no Anthropic or OpenAI specific headers by default)
- Write tests for all ordering and budget behaviors

## Implementation Notes

- The stable prefix (sections 1–5) must be bit-for-bit identical across calls with the same project_id and operating context. Any non-determinism in those sections defeats the cache.
- Token budget enforcement drops or compresses dynamic content first, then project truth packet, then project memory summary. System instructions and AIOS operating rules are never dropped.
- Deduplication prevents the same fact appearing in both the stable truth packet and the dynamic retrieved memory. The dynamic copy is always the one dropped.
- Provider-agnostic means no `anthropic-beta: prompt-caching-2024-07-31` headers or OpenAI cache-control flags are injected by default. A future adapter pattern can add them cleanly if needed.
