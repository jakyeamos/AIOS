# Plan 12-06: Retrieval Quality Checks and Tests

## Objective

Add integration tests and a standalone validation script that prevent AIOS from degrading into naive semantic-search-only behavior. Tests verify the nine retrieval quality constraints from the memory packet contract.

## Scope

- Write `tests/memory/test_packet_quality.py` with integration tests for all nine constraints
- Write `tests/context/test_context_quality.py` for `ContextCompiler` ordering and deduplication
- Write `scripts/validate-memory-packets.py` as a standalone CI-runnable validation tool

## Implementation Notes

- Tests are integration-level: they call `MemoryCompiler` and `ContextCompiler` with fixture data. Unit tests of internal helpers are not the goal here — behavioral guarantees are.
- The validation script must work as a standalone CLI tool without needing a running AIOS database. It validates a packet markdown file in isolation.
- If `tests/memory/` or `tests/context/` directories do not exist, create them with empty `__init__.py` files.
- The script should produce human-readable violation messages, not just exit codes.
