# Plan 12-02: Layered Memory Schema (Layers A–C)

## Objective

Add the SQLite tables and Python module layer for Layers A (raw source), B (normalized facts), and C (graph relationships). This is the durable storage foundation that Plans 12-03 and 12-04 build on.

## Scope

- Add four idempotent migration helpers to `schema.sql`
- Implement `services/memory_layers.py` with one composable class per layer
- Write tests covering insert, query, validation, and idempotent migration

## Implementation Notes

- Do not implement a graph database. Use SQLite rows with (subject_id, predicate, object_id) triples for Layer C.
- Each layer module is independent. No shared mutable state, no MemoryManager god class.
- The four tables extend the existing schema without touching existing tables.
- Idempotent helpers follow the same pattern as `_ensure_workflow_learning_signal_kind_column` in `bin/aios_orchestration_runtime.py`.
