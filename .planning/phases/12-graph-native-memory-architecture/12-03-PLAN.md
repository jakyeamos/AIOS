# Plan 12-03: Memory Compiler and Briefing Packets (Layer D)

## Objective

Implement `services/memory_compiler.py`, the module that translates retrieved raw/fact/graph memory into model-readable Layer D briefing packets. This is the primary model-facing output of the Phase 12 memory system.

## Scope

- Implement `MemoryCompiler` with a `compile()` method
- Produce structured markdown packets with defined sections
- Enforce staleness filtering, provenance inclusion, token budget, and mode parameter
- Never return raw JSON or graph rows to callers
- Write tests for all behavioral constraints

## Implementation Notes

- The compiler is a pure transformer: it takes pre-fetched rows from `services/memory_layers.py` and produces markdown. No I/O inside `compile()`.
- Causal chain traversal has a 3-hop depth cap to prevent runaway graph walks on large datasets.
- Token budget enforcement uses priority-based section dropping, not character truncation mid-sentence.
- The packet must always include Sources/Provenance even when token budget is tight. Sources section is never dropped.
