# Plan 16-06: Retrospective, Model-Selection, And Shadow Parity Metadata

## Objective

Close the feedback loop without making AIOS silently self-modify. Repeated failures should produce structured, reviewable retrospective artifacts and improvement proposals. Model choices and shadow-branch comparisons should be inspectable enough to evaluate whether the harness is choosing the right agent/model/reasoning level for each phase.

## Scope

Patch existing learning, model routing, and shadow-branch surfaces.

Targets:

- structured retrospective artifact schema
- model-selection logging
- shadow parity metadata enrichment
- CLI inspection
- tests covering persistence and no-auto-apply behavior

## Retrospective Artifact Fields

- `task_id`
- `outcome`: `success | partial | failure`
- `failed_phase`
- `root_cause_category`
- `evidence`
- `harness_gap`
- `proposed_change`
- `target_file_or_component`
- `risk`: `low | medium | high`
- `auto_apply`: always false for major harness changes
- `should_become`: `rule | check | playbook | benchmark | memory | model_routing_update | doc`

## Model Selection Fields

- `task_id`
- `phase`
- `task_type`
- `selected_model`
- `reasoning_level`
- `selection_reason`
- `fallback_model`
- `tokens_used`
- `cost_estimate`
- `latency_ms`
- `outcome`

## Standards

- Retrospectives propose; they do not auto-apply major harness changes.
- Preserve existing shadow branch workflow and branch naming.
- Do not require token/cost data when providers do not expose it; store null plus caveat.
- Failure categories must include missing context, wrong model, bad decomposition, weak verification, missing test, unclear acceptance criteria, tool failure, bad retrieval, overbroad edit, architecture misunderstanding, second-brain miss, prompt/template flaw, and deterministic harness gap.

## Verification

- Tests prove retrospective artifacts default to `auto_apply=false`.
- Tests prove model-selection records tolerate unavailable token/cost values.
- Tests prove shadow parity metadata can be queried without mutating branches.
