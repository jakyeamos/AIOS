# Plan 20-07: Internal Planning Schema And Logs

## Objective

Represent planning context in structured, agent-friendly fields and log enough data to evaluate whether execution-symmetric planning reduces rework.

## Scope

Add planning context and logging helpers. Use existing persistence if possible; add schema only if the audit shows no suitable storage.

## Required Log Fields

- source invocation type and raw invocation
- workflow
- phase
- task type
- selected lenses
- output format
- validation depth
- handoff target
- sub-agent strategy
- model strategy
- TMCP packet id
- TMCP receipt id
- TMCP bypass reason, when a managed run explicitly skips packet compilation
- execution result
- validation result
- rework required
- notes

## Verification

- Tests cover planning context creation.
- Tests cover log serialization.
- Tests tolerate missing execution/validation results before execution has happened.
- Tests cover non-trivial managed-run TMCP packet/receipt emission as a default adoption contract.
- Tests cover explicit managed-run bypass metadata instead of silent TMCP omission.
