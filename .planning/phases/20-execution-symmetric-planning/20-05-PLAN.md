# Plan 20-05: Skill-As-Planning-Lens

## Objective

Allow execution, review, validation, and audit skills to shape plans before implementation instead of only reviewing completed work.

## Scope

Add skill planning-lens translation for the initial high-value skills identified by the audit.

Planning behavior should:

- identify likely constraints and risks
- add validation gates
- define reviewable artifacts
- preserve behavior and interfaces where relevant
- avoid producing final review findings
- avoid blocking unless a major unresolved risk exists

## Verification

- Tests cover a testing skill as planning lens.
- Tests cover a security/review skill as planning lens.
- Tests prove planning mode does not produce completed-work review output.
