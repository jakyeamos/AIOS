# Plan 20-03: GSD Workflow Phase Recognition

## Objective

Recognize GSD planning, implementation, review, and validation phases as structured workflow phases, not generic slash commands.

## Scope

Add a configurable GSD phase registry and a workflow detection helper.

Detect:

- direct planning requests
- `/gsdplanphase` or equivalent
- `/gsdimplementphase`
- `/gsdreviewphase`
- `/gsdvalidatephase`
- slash command overrides such as `/no-subagents`
- audit-to-implementation flows
- prompt-generation flows

## Verification

- Tests cover `/gsdplanphase`.
- Tests cover natural-language planning.
- Tests cover slash command override behavior.
- Tests prove configured aliases can change without code edits.
