# Plan 20-02: Core Principle And Complexity Contract

## Objective

Make Execution-Symmetric Planning an explicit AIOS principle and define how plan depth scales with task complexity.

## Scope

Add documentation and machine-readable policy for:

- trivial
- simple
- moderate
- complex
- high_risk

## Complexity Behavior

- `trivial`: direct answer or minimal plan
- `simple`: light plan with objective, safest next step, validation
- `moderate`: execution-symmetric plan with selected lenses
- `complex`: full plan with risks, validation, rollback, and handoff
- `high_risk`: full plan with explicit constraints, review gates, rollback, and escalation criteria

## Verification

- Policy is parseable.
- Docs define non-overplanning guardrail.
- AIOS rule authority references the principle.
