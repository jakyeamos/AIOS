# Plan 18-06: Shadow Evaluation Plans And Meta CLI

## Objective

Connect meta-learning proposals to review workflows and shadow-branch validation. Add a minimal command interface so operators can inspect signals and proposals without editing files manually.

## Scope

Add:

- shadow eval plan generator
- minimal `aios meta` CLI commands, if compatible with existing CLI style

Example commands:

- `aios meta audit`
- `aios meta analyze-session <path>`
- `aios meta analyze-sessions <dir>`
- `aios meta proposals`
- `aios meta apply <proposal-id>`
- `aios meta reject <proposal-id>`
- `aios meta eval <proposal-id>`

## Verification

- Tests cover eval plan generation.
- Tests cover CLI command parsing for at least analyze-session, proposals, and eval.
- Tests prove medium/high-impact proposals get eval plans or documented exemptions.
