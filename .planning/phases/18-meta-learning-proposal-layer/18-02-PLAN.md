# Plan 18-02: Session Signal Extractor

## Objective

Implement a lightweight session signal extractor that can analyze session logs, transcript exports, or structured workflow traces and output normalized meta-learning signals.

## Scope

Create `services/meta_learning_signals.py` unless Plan 18-01 identifies an existing better module.

Support fixture/mock transcript input first. Add broader provider support only if it falls out cleanly from existing session ingestion surfaces.

## Signal Types

Support:

- `explicit_correction`
- `repeated_pattern`
- `approval`
- `command_repetition`
- `tool_friction`
- `context_miss`
- `model_mismatch`
- `contradiction`

## Verification

- Tests cover explicit correction detection.
- Tests cover repeated pattern aggregation.
- Tests cover contradiction extraction.
- Tests prove output has stable IDs for the same input.
