Extend the standards registry so all ten DELT-01 quality dimensions have at least one signal and verify the Provenance import path is clean for the delta-explanation projection in plan 07-02.

Purpose: DELT-01 names ten dimensions but `config/standards/registry.json` only covers seven distinct domains today. Output: a registry bumped to profile version `2026.06.0` with five new standards entries, five new evaluator branches that return `unknown` with explicit reasons, and tests proving the ten-domain rollup is present.
