Ship the Python search backend that powers OPER-01: cross-entity search across runs, packets, writebacks, findings, prompts, skills, workflows, knowledge, route decisions, deltas, backfill tasks, automations, experiments, divergent runs, learning patterns, and promotion lifecycle items. Purpose: OPER-01 requires searchable, inspectable operator views. The existing tRPC routers list rows but offer no `query` parameter and no cross-entity search. This plan ships the backend that the UI projection (Plan 04) and tRPC router (Plan 05) consume; the CLI is parity for headless operators.

       `_score_hit(*, query, title, summary, key, last_updated_at, now)`:
       - base = 0.0
       - if query == "" -> return recency component only.
       - if query lowercased substring in title.lower() -> base += 0.5
       - if query lowercased substring in summary.lower() -> base += 0.3
       - if query.strip().lower() == key.lower() -> base += EXACT_KEY_BOOST
       - parse last_updated_at to datetime; compute age_days = (now - parsed).days; recency = exp-decay using half-life of RECENCY_BOOST_HALF_LIFE_DAYS: `recency = 0.2 * (0.5 ** (age_days / RECENCY_BOOST_HALF_LIFE_DAYS))` (capped at 0.2 max contribution).
       - return min(base + recency, 1.0).

       Per-kind functions (one per EntityKind literal value). Pattern for each:
       ```
       def _search_runs(conn, *, query, project_id, now) -> list[OperatorSearchHit]:
           if not _safe_table_exists(conn, "orchestration_runs"):
               logger.debug("operator_search: orchestration_runs table missing; skipping")
               return []
           like = f"%{query}%" if query else None
           params: list[Any] = []
           clauses: list[str] = []
           if like is not None:
               clauses.append("(objective LIKE ? OR id LIKE ?)")
               params.extend([like, like])
           if project_id is not None:
               clauses.append("project_id = ?")
               params.append(project_id)
           where = (" WHERE " + " AND ".join(clauses)) if clauses else ""
           order = " ORDER BY COALESCE(updated_at, created_at) DESC"
           limit = " LIMIT ?"
           params.append(PER_KIND_CAP)
           sql = f"SELECT id, objective, project_id, status, COALESCE(updated_at, created_at) AS last_updated_at FROM orchestration_runs{where}{order}{limit}"
           hits: list[OperatorSearchHit] = []
           for row in conn.execute(sql, params).fetchall():
               score = _score_hit(query=query, title=row["objective"] or "", summary=row["status"] or "", key=row["id"] or "", last_updated_at=row["last_updated_at"], now=now)
               hits.append(OperatorSearchHit(
                   kind="run",
                   id=row["id"],
                   title=row["objective"] or row["id"],
                   summary=f"status: {row['status']}",
                   project_id=row["project_id"],
                   score=score,
                   source_table="orchestration_runs",
                   last_updated_at=row["last_updated_at"],
                   drill_down_path=_drill_down_for("run", id_=row["id"]),
                   metadata={"status": row["status"]},
               ))
           return hits
       ```
