<objective>
Create the Agent Eval Foundation: the docs, templates, schemas, and AGENTS.md rules that let agents immediately run a structured eval after major work. This is Phase 1 of the eight-phase AIOS Testing & Benchmark Evaluation rollout. It creates no automation — only the behavioral contract, vocabulary, and templates that subsequent automation phases will instrument.

Purpose: AIOS currently produces outputs but cannot prove whether those outputs are better than the baseline. The eval foundation gives every future run a declared context profile (jakye_second_brain_full vs peer_repo_only vs external_clean_room), a failure taxonomy, a scorecard formula, and a set of agent-fillable templates. It also extends AGENTS.md with the eval workflow rule so agents run the checklist automatically after large work without being prompted.

This plan extends the existing docs/evals/aios-harness-eval-v0.md (deterministic fixture-backed harness eval) with the higher-level benchmark evaluation architecture. The harness eval is not replaced or modified — it becomes one evaluation mode within the broader system.

Output: 7 new docs/templates; 1 new Python schema file; 1 AGENTS.md extension. No new Python services, no new SQLite tables, no new tests beyond what is already required for the schema type definitions.
</objective>
