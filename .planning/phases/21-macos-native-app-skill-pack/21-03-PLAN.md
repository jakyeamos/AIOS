# Plan 21-03: macOS Project Detection And Build Verification

## Objective

Create the foundational macOS skills: project detection and xcodebuild verification.

## Scope

Use the target paths from Plan 21-01. If the paths listed in frontmatter do not match discovered conventions, use the discovered convention and update artifacts accordingly.

## Required Decision Tree

Project detection:

- If no macOS/Xcode project is found, exit with `not applicable`.
- Else classify project shape and emit facts for downstream tasks.

Build verification:

- If the user asks to build, compile, check build, run xcodebuild, or fix build errors, invoke project detection.
- Choose workspace/project.
- List schemes.
- Build selected scheme.
- Parse result.
- Report success or repair errors and rerun.

## Verification

- Behavioral tests cover workspace plus project, project-only, no Xcode project, multiple schemes, missing scheme, package dependencies unresolved, and signing identity failure.
