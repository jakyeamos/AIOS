# Plan 21-06: macOS Release Pipeline Skill

## Objective

Create a dry-run-first macOS release pipeline skill with strong mutation gates.

## Scope

Transform donor release guidance into AIOS/TMCP skill format.

## Hard Gates

Never run without explicit approval:

- `git commit`
- `git push`
- `gh release create`
- appcast modification
- signing release artifacts
- notarization submission
- artifact publishing
- version/build changes

## Verification

- Tests cover dry-run release, duplicate build number, missing create-dmg, missing gh auth, sign_update missing, appcast invalid XML, attempted git push without permission, and attempted GitHub release without permission.
