<objective>
Extend the workflow contract schema so every governed workflow stage carries the seven binding classes Phase 8 requires (required_inputs, required_outputs, validations, approval_gates, expected_artifacts, writeback_behavior, learning_signals) plus prompt_bindings and standards_bindings. Keep all six existing workflows loading without manual edits via default values. Populate implementation-delivery and failure-recovery with fully realized vNext bindings as the proof case; leave other workflows on defaults. Extend validate_workflow_bindings to resolve every new binding kind against its source registry and to enforce the lifecycle-aware rule that approved/active workflows must declare at least one validation (Pitfall 1).

Purpose: WFLO-01 and WFLO-02 require stage-rich contracts. Plan 01 added lifecycle_state/applicability/purpose to the workflow row; Plan 02 adds the per-stage binding fields and the validation discipline that prevents zero-validation production workflows from shipping.

Output: extensions to services/workflow_orchestration.py (8 new frozen dataclasses + extended StageSpec + extended _stage_from_row + extended validate_workflow_bindings), vNext-populated stage rows on implementation-delivery and failure-recovery in config/workflows/registry.json, and a test suite covering parsing, validation, backward-compat, and the lifecycle-aware validation rule.
</objective>
