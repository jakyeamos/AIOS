<objective>
Create the shadow branch testing infrastructure: worktree creation, contamination verification, diff/test capture, and Shadow Branch Delta computation. This is the mechanism that makes paired comparisons (same task, same repo state, different conditions) possible.

Purpose: The design spec's core fairness rule is "do not compare AIOS on Task A against baseline on Task B." This plan enforces that rule programmatically — shadow branches always share a start SHA, contamination is checked before any comparison is recorded, and the delta is computed from structured EvalScore rows rather than subjective assessment.

Output: schema.sql extension (1 new table); services/shadow_branch_runner.py NEW; services/aios_cli.py extension (3 subcommands); test coverage with mocked git subprocess.
</objective>
