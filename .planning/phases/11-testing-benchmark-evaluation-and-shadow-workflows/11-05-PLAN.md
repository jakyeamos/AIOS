<objective>
Create the peer passive trace infrastructure: privacy-safe session observation, shadow candidate scoring, and the policy configuration that ensures AIOS never mutates peer workflows in trace mode. This is the read-only foundation that peer automated shadow benchmarks (Plan 11-06) build on.

Purpose: The design spec requires that peer trace mode has a friction budget — no more than 5% increase in task time or token usage, no prompt mutation, no repo writes. This plan enforces those constraints in code, not just in docs. The shadow candidate scorer gives every observed task a quantified score so the human approval conversation in Plan 11-06 is informed rather than arbitrary.

Output: schema.sql extension (3 new tables); services/peer_trace.py NEW; services/shadow_candidate_scorer.py NEW; bin/hook-session-stop.py extension; config/peer-eval/peer-trace-policy.json NEW; services/aios_cli.py extension (5 subcommands); test coverage.
</objective>
