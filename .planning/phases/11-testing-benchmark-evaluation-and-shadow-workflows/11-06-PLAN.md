<objective>
Create the peer automated shadow benchmark pipeline: the full 14-state automation state machine that converts an in-person-approved candidate into an isolated shadow run, verification, scorecard, comparison report, and backlog items — all without touching the peer's active branch.

Purpose: The design spec's core peer benchmark principle is "human approval stays social; execution is automated." This plan implements the execution half. After `aios shadow approve`, the rest runs automatically. Every state transition is persisted before the work begins, so partial failures leave a clear audit trail.

Output: services/shadow_automation.py NEW (the most complex service in Phase 11); services/aios_cli.py extension (3 subcommands); test coverage with fully mocked subprocess calls.
</objective>
