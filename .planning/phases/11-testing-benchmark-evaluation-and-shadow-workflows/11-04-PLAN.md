<objective>
Create the feature ablation runner and complete the eight-condition ablation policy suite. This proves which AIOS features actually create lift by comparing full AIOS against systematically disabled variants.

Purpose: The design spec's ablation requirements (EVAL-04) exist to prevent AIOS from claiming credit for lift that comes from model capability alone. The ablation runner makes this falsifiable: if removing context packets doesn't hurt scores, the context packet system is not contributing. If removing subagents hurts scores, subagent orchestration is worth its cost.

Output: 4 additional ablation policy JSON files (completing the 8-policy suite); services/ablation_runner.py NEW; services/aios_cli.py extension (2 subcommands); test coverage.
</objective>
