<objective>
Create the eval run record infrastructure: five new SQLite tables and the EvalRunService that agents use to persist eval results. This is the data foundation that all subsequent Phase 11 plans write to.

Purpose: AIOS currently has no structured way to record that a task was evaluated, what condition it ran under, what context profile it used, or what score it received. This plan creates the minimal durable store. Future plans (shadow branch runner, ablation runner, peer trace, external adapter) all write to these tables.

Output: schema.sql extension (5 new tables); services/eval_run_service.py NEW; services/aios_cli.py extension (3 new subcommands); 2 test file additions.
</objective>
