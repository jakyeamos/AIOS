# Plan 15-01: Skill Inventory Audit — Discovery, Comparison Matrix, And Backup Protocol

## Objective

Audit the full local Claude Code skill portfolio, compare each upstream target skill against local equivalents, produce a structured inventory with merge/add/leave decisions, and create a timestamped backup before any skill file is touched.

This plan is read-only for skill files. No modifications to existing skills.

## Step 1: Create Timestamped Backup

Before reading any skill file, create a backup:

```bash
TIMESTAMP=$(date +%Y%m%d-%H%M%S)
cp -r ~/.claude/skills ~/.claude/skills-backup-${TIMESTAMP}
echo "Backup created: ~/.claude/skills-backup-${TIMESTAMP}"
```

Record the backup path in `docs/phase-15-skill-inventory.md`.

## Step 2: Scan All Skill Locations

Scan each location from the research doc:

1. `~/.claude/skills/` — list all `.md` files
2. Plugin-installed skills under `/Users/jakyeamos/.claude/plugins/`
3. `~/AIOS/.claude/` — any project-level overrides
4. `~/projects/Terrace/.claude/` — Terrace-scoped skills

For each discovered file, read the frontmatter (`name`, `description`) and the first section of the body to extract purpose.

## Step 3: Fetch Upstream Skill Summaries

For each of the seven upstream target skills, read the source spec summary from `15-RESEARCH.md:source_skills`. Do not fetch from GitHub at runtime — the research doc is the authoritative source for this plan.

## Step 4: Build Comparison Matrix

For each upstream skill, identify zero or more local equivalents. Assign a recommended action:

| Action | When to use |
|--------|-------------|
| **merge** | Local skill covers significant ground; additive behaviors can be spliced in without a rewrite |
| **add-new** | No local equivalent exists or local equivalent is in an incompatible plugin namespace |
| **leave-alone** | Local skill already covers the target behavior well enough; upstream adds nothing |

Document each decision with justification.

## Step 5: Write Inventory

Write `docs/phase-15-skill-inventory.md` with:

1. Backup path and timestamp
2. Full discovered skill table (path, name, purpose, overlap, action)
3. Decision table for each of the seven upstream targets
4. Any unresolved questions surfaced during discovery that future plans must answer

## Standards

- This plan is read-only for skill files. No edits to any skill.
- The inventory is the contract that Plans 15-02 through 15-08 execute against — it must be accurate before proceeding.
- Flag any skill that is project-scoped (Terrace-only, AIOS-only) and note that globalizing it requires explicit justification.
