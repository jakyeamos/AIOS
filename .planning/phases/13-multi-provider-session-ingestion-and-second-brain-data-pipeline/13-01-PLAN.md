# Plan 13-01: Audit Existing Claude/Codex Ingestion Pipeline

## Objective

Read and map the entire existing session ingestion codebase. Produce a written audit that is the authoritative input contract for the provider interface design in Plan 13-02.

## Scope

Inspect and document:

1. **Entry points** — all scripts and hooks that currently ingest or generate session data:
   - `bin/hook-session-start.py`
   - `bin/hook-stop.py`
   - `bin/hook-prompt-submit.py`
   - `bin/import_ai_history.py`
   - `bin/import-ai-history.py` (CLI wrapper)
   - `bin/cron-ingest-codex.py`
   - `bin/auto_ingest.sh`

2. **Database schema** — all tables in `aios.db` that the ingestion pipeline reads or writes:
   - `processed_files`
   - any sessions, invocations, conversation, or summary tables
   - exact column names, types, and constraints

3. **Data flow** — trace a session from raw file to DB to summary JSON to vault note for both Claude and Codex

4. **Deduplication strategy** — how `processed_files` works, what it misses (mtime changes, content hash changes, renamed paths)

5. **Obsidian writeback** — how `auto_ingest.sh` reads summary JSON and writes vault markdown; what fields are used; what privacy rules are applied

6. **Abstraction gaps** — where provider-specific logic is hardcoded vs. what a provider interface could generalize

7. **Integration points** — ranked list of exactly where Cursor and Antigravity must hook in to be consistent with Claude/Codex behavior

## Output

Write `docs/audits/session-ingestion-audit.md` with sections:
1. Code Map (entry points, file paths, key functions)
2. Database Schema Inventory (all relevant tables with columns)
3. Data Flow Trace (Claude path + Codex path)
4. Deduplication Strategy And Gaps
5. Obsidian Writeback Flow
6. Abstraction Gaps
7. Integration Points (ranked)

## Standards

- Every finding references an actual file path and function name or line range.
- Do not propose solutions — describe current state accurately.
- The audit must be sufficient for a new engineer to understand the full pipeline without reading the source.
