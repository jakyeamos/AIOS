# Plan 13-02: Provider Interface Abstraction And DB Migrations

## Objective

Introduce the `SessionProvider` abstract base class and the `NormalizedSession` model. Wrap existing Claude and Codex ingestion in conforming provider classes. Add the `session_provider_cursors` DB table. All existing behavior and tests must remain intact.

## Scope

### 1. Provider interface (`services/session_providers/base.py`)

Define `SessionProvider` as an abstract base class with these nine methods:

| Method | Signature | Purpose |
|--------|-----------|---------|
| `discover_sources` | `() -> list[SourcePath]` | Find all candidate source files/DBs for this provider |
| `scan_since` | `(last_cursor: ProviderCursor) -> list[SourcePath]` | Return sources modified since last scan |
| `extract_raw_session` | `(source: SourcePath) -> RawSession` | Read raw content from one source without normalizing |
| `normalize_session` | `(raw: RawSession) -> NormalizedSession` | Convert raw to normalized model |
| `compute_fingerprint` | `(normalized: NormalizedSession) -> str` | Stable content hash for dedup |
| `upsert_session` | `(normalized: NormalizedSession) -> str` | Write to DB; return stable_session_id |
| `summarize_session` | `(session_id: str) -> SummaryResult` | Generate structured summary |
| `emit_writeback_candidates` | `(session_id: str) -> list[WritebackCandidate]` | Produce writeback proposal records |
| `health_check` | `() -> HealthStatus` | Report provider reachability and source counts |

Define `NormalizedSession` as a dataclass or TypedDict with all fields from the spec.

### 2. Claude provider (`services/session_providers/claude.py`)

Wrap the existing hook-based and export-based Claude ingestion. Do not move or rewrite the hook scripts — the provider is an adapter that calls existing logic.

### 3. Codex provider (`services/session_providers/codex.py`)

Wrap `cron-ingest-codex.py` logic. The cron script continues to work independently; the provider class is an additional interface over the same logic.

### 4. Provider registry (`services/session_providers/__init__.py`)

Export a `PROVIDERS` dict mapping `provider_id` string to provider class. New providers in later plans register here.

### 5. DB migration

Add `session_provider_cursors` table:
```sql
CREATE TABLE IF NOT EXISTS session_provider_cursors (
    provider_id          TEXT NOT NULL,
    source_path          TEXT NOT NULL,
    last_mtime           REAL,
    last_size            INTEGER,
    last_hash            TEXT,
    last_provider_session_id TEXT,
    last_scanned_at      TEXT,
    PRIMARY KEY (provider_id, source_path)
);
```

## Standards

- No existing test may be broken.
- Claude/Codex provider wrappers must delegate to existing logic — no reimplementation.
- The provider interface must be minimal: no over-engineering for hypothetical future providers beyond what Cursor and Antigravity require in Plans 13-03/13-04.
