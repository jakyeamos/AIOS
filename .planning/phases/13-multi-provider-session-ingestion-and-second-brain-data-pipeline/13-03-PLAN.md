# Plan 13-03: Cursor Provider Implementation

## Objective

Implement the Cursor `SessionProvider`. Discover, extract, normalize, and upsert Cursor sessions from local SQLite workspace databases and agent-transcript JSONL files.

## Scope

### Source discovery (macOS paths)

```
~/Library/Application Support/Cursor/User/workspaceStorage/**/state.vscdb
~/Library/Application Support/Cursor/User/globalStorage/state.vscdb
~/.cursor/projects/**/agent-transcripts/*.jsonl
```

Linux equivalents (`~/.config/Cursor/...`) should be detected but are not the primary target.

### SQLite access rules

- Open all Cursor `.vscdb` files **read-only** (`sqlite3.connect(path, uri=True)` with `?mode=ro`)
- If a `database is locked` error occurs, copy to a temp file and read from the copy
- Never write to any Cursor SQLite database

### ItemTable inspection

Do not assume a fixed set of keys. For each `.vscdb`:
1. Run `SELECT key, value FROM ItemTable`
2. Filter for keys that contain any of: `chat`, `composer`, `aichat`, `agent`, `conversation`, `aiService.prompts`
3. Attempt JSON parse on each candidate value; skip non-JSON values
4. Extract chat/message arrays from whichever keys contain them

### Workspace hash and path mapping

- The `workspaceStorage` subfolder name is a hash of the workspace folder path
- Read `workspaceStorage/<hash>/workspace.json` to resolve the hash to an absolute path
- Store both: `workspace_id = hash`, `workspace_path = resolved_folder_path`
- If the resolved path no longer exists (renamed/moved workspace), store the hash and `None` for path with a flag `workspace_orphaned = True`

### JSONL agent transcripts

- Parse `~/.cursor/projects/**/agent-transcripts/*.jsonl` as newline-delimited JSON
- Extract: session metadata from first/last events, messages, tool calls, file edits

### Deduplication between SQLite and JSONL sources

If both sources describe the same session (matched by provider_session_id or timestamp+workspace overlap), merge into one `NormalizedSession`. Prefer JSONL for message content if richer; prefer SQLite for session metadata if more complete.

### Debug mode

`health_check()` returns a `HealthStatus` with:
- discovered source count by type (workspace DBs, global DB, JSONL files)
- session count per source
- any lock/read errors
- no message content

### Platform detection

Use `platform.system()` to select the correct base path. Log a warning (not an error) if on Linux or Windows where paths differ.

## Standards

- Never mutate any Cursor file or database.
- Temp copies go to `~/AIOS/staging/cursor-snapshots/` and are deleted after read.
- Unknown ItemTable value formats are logged and skipped, not raised as errors.
- Orphaned workspaces are stored with metadata, not silently dropped.
