# Plan 19-01: Native Command Pack Audit

## Objective

Audit AIOS before implementing native workflow commands. The result should prevent a plugin clone and identify the correct command, skill, workflow, or prompt surfaces for each candidate.

## Scope

Create `docs/audits/aios-native-command-pack-audit.md`.

Required sections:

- Current architecture
- Fit analysis per candidate command
- Safety analysis
- MVP implementation order
- Deferred commands and rationale
- Test and logging plan

## Candidate Commands

Evaluate:

- `squad-review`
- `handoff`
- `zoom-out`
- `de-slopify`
- `security-audit`
- `prototype`
- `codebase-rehab`
- `codebase-sweep`

## Verification

- Audit exists and covers all candidate commands.
- Audit identifies read-only, modifying, confirmation-required, and shadow-branch-only commands.
- Audit recommends `zoom-out`, `handoff`, and `squad-review` as the first read-only core unless current repo evidence contradicts that order.
