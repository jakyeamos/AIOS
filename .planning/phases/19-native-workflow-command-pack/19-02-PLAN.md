# Plan 19-02: Command Contracts, Schemas, And Safety Classes

## Objective

Define command contracts before implementation so every native workflow command has a clear schema, safety profile, and logging expectation.

## Scope

Create or extend the command registry selected by Plan 19-01.

Define contracts for:

- `aios zoom-out`
- `aios handoff`
- `aios review squad`
- `aios audit security`
- `aios cleanup de-slopify`
- `aios prototype`

## Safety Classes

Use:

- `read_only`
- `artifact_write`
- `guarded_modify`
- `sandbox_write`
- `shadow_branch_only`

## Verification

- JSON metadata parses.
- Docs cover all six MVP commands.
- Every command has input/output schema and safety class.
