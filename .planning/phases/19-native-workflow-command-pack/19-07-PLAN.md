# Plan 19-07: Tests And Documentation

## Objective

Complete tests and documentation for the native workflow command pack.

## Scope

Create `docs/aios/native-workflow-commands.md` and finish test coverage across command registration, schemas, safety classes, and outputs.

## Required Workflows In Docs

For unfamiliar code:

1. `aios zoom-out`
2. implement task
3. `aios review squad`
4. `aios cleanup de-slopify`
5. run tests
6. `aios handoff`

For risky/security-sensitive work:

1. `aios zoom-out`
2. implement task
3. `aios audit security --mode practical`
4. `aios review squad`
5. run tests
6. `aios handoff`

For uncertain design ideas:

1. `aios prototype`
2. review result
3. promote only if useful
4. implement production version
5. `aios review squad`

## Verification

- Tests cover all required behaviors from the source spec.
- Docs are concrete and avoid plugin-clone framing.
- `pnpm context:validate` passes.
