# Plan 19-03: Read-Only MVP Commands

## Objective

Implement the first true AIOS command core: `zoom-out`, `handoff`, and `review squad`.

## Scope

Implement read-only command behavior through the existing CLI architecture.

Required outputs:

- `# Zoom-Out Report`
- `# AIOS Handoff`
- `# Squad Review`

## Standards

- Do not edit source files.
- Keep output structured and stable.
- Separate confirmed findings from speculation in squad review.
- Prefer current repo data and git state over invented context.

## Verification

- Tests prove read-only commands do not modify target files.
- Tests prove all required sections are present.
- Tests prove squad review includes all reviewer lanes.
