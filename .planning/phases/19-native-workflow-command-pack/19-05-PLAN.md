# Plan 19-05: Guarded Cleanup And Prototype Commands

## Objective

Add the two non-read-only commands with explicit guardrails: conservative cleanup and isolated prototypes.

## Scope

Implement:

- `aios cleanup de-slopify`
- `aios prototype`

## Standards

- De-slopify must preserve behavior.
- De-slopify must not remove public APIs, config keys, structural code, or meaningful state without explicit approval.
- Prototype artifacts must be isolated.
- Prototype output must include cleanup and promotion guidance.

## Verification

- Tests prove de-slopify refuses or flags risky structural changes.
- Tests prove prototype writes only to allowed prototype locations.
- Tests prove required output sections are present.
