# Plan 19-06: Command Metadata Logging

## Objective

Add lightweight command metadata logging so native workflow commands can later be evaluated in shadow branches and workflow delta analysis.

## Scope

Create a local logging helper and wire it into implemented commands.

## Required Metadata

- Command name
- Timestamp
- Repo/project
- Branch
- Scope
- Read-only vs modifying
- Model/reasoning level if available
- Sub-agents/reviewer lanes used
- Files touched
- Tests run
- Pass/fail status
- User confirmation required
- User confirmation received
- Token/cost estimate if available
- Runtime if available

## Verification

- Tests cover logging shape.
- Tests cover unavailable optional fields.
- Tests prove no external telemetry is used.
