| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-27-09 | Denial of Service | missing audit-and-plan execution strategy | mitigate | Return explicit missing-strategy metadata instead of raising an uncaught strategy selection error. |
</threat_model>
