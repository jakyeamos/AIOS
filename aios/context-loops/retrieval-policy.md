# Context Loop Retrieval Policy

Use the smallest useful context set before drafting.

## Always Read

- `aios/context-loops/approved-lessons.md`
- task-local input supplied by the operator

## Prefer

- current thread or task artifact
- recent project truth files
- source-backed memory packets
- prior decisions from trusted project docs
- relationship context only when explicitly approved for durable use

## Avoid

- broad semantic search as a substitute for authoritative routing nodes
- raw private context unless the operator explicitly approved it for this workflow
- treating one edit as a durable preference
- silently promoting lessons into future retrieval

## Email Pilot

Email drafting may use manual input and approved lessons. Real mailbox, calendar, tracker, and thread retrieval are deferred until the integration can preserve provenance and draft-only safety.
