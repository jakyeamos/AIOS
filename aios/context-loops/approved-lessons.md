# Approved Context Loop Lessons

Only human-approved lessons belong here. The inner loop reads this file before drafting.

## Email Drafting

### Tone / Relationship Context

- For close collaborators with prior informal tone, avoid overly formal openings unless the current thread is formal.

### Commitment Safety

- Do not commit to deadlines, meetings, deliverables, scope, pricing, or availability unless directly supported by calendar, prior thread, project tracker, trusted source, or explicit user instruction.

### Retrieval Rules

- Before replying to project-related email, prefer prior thread history and project notes over generic memory search.

### Human-Handoff Rules

- If the reply accepts scope, promises delivery, quotes pricing, or makes legal or business commitments, draft only and flag for human review.
