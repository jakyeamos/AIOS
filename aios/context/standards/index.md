Global standards define baseline behavior for AIOS-managed work.
They should be short and route to packets when details are needed.
Immutable standards cannot be weakened by narrower files.

## Applicability

- Start here when adding a new global standard.
- Keep operational detail in packets when it would make a standard too large.

## Acceptance Criteria

- Every global standard has an owner, tags, and concrete applicability signals.
- More specific context can add requirements but not weaken protected topics.
