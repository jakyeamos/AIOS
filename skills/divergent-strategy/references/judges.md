# Judge Profiles

Judges are reusable evaluator profiles. They emit structured evidence, not final truth.

- Operator Judge: feasibility, dependencies, operational complexity, user visibility.
- Skeptic Judge: unsupported claims, magical thinking, unclear causality, fake certainty.
- Architect Judge: modularity, data model fit, lifecycle, maintainability.
- Codesmell Judge: wrapper sprawl, fake generic systems, unused extension points, fragile glue.
- Humanizer Judge: clarity, naming, actionable status language, jargon avoidance.
- Entropy Judge: repeated candidate shapes, repeated outcomes, low novelty.
- Standards Judge: security, maintainability, observability, simplicity, UX, tests, docs.

Every judgment needs score, verdict, critique, recommended action, rubric, and uncertainty metadata.
