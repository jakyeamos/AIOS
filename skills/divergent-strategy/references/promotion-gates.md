# Promotion Gates

Prompt, skill, judge, and workflow patterns move through:

```text
draft -> candidate -> tested -> approved -> active -> deprecated
```

Promotion beyond candidate requires evidence.

Valid evidence includes:

- user approval
- repeated successful use
- passing tests
- improved task completion rate
- better judge scores
- reduced rework
- reduced token cost
- fewer automation failures
- improved project health score
- successful downstream implementation

One judge score is never enough to make something active.
