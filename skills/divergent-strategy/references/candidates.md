# Candidate Profiles

Candidates are strategic angles, not random samples.

- Conservative Integrator: minimal change, existing architecture first.
- Systems Architect: durable long-term data and workflow boundary.
- Workflow Designer: procedure, agent steps, and operator checkpoints.
- Product Operator: UI visibility, approvals, and day-to-day usefulness.
- Skeptical Minimalist: smallest viable implementation and anti-abstraction pressure.
- Researcher: prior-art extraction without copying terminology.
- Chaos / Novelty Candidate: high-variance opportunity and hidden failure discovery.
- Standards Enforcer: success criteria, verification, and measurable quality.

Each candidate must include proposal, implementation shape, risks, best use case, why it might fail, and memory candidates.
