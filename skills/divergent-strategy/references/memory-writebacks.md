# Memory Writebacks

Memory writebacks are proposals unless a project policy explicitly permits automatic mutation.

## HOW Memory

Reusable cross-project process knowledge and preferences.

## WHAT Memory

Project-specific facts, constraints, decisions, and architecture.

## FAILURE Memory

Useful failures, weak assumptions, dead ends, and impossible formulations worth preserving.

## ENTROPY Memory

Convergence observations, repeated judge sets, repeated candidate shapes, and novelty risks.

Writebacks must include proposed content, rationale, evidence, status, and reviewer metadata when approved or rejected.
