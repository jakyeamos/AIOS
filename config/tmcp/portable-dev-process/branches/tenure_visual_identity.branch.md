## Source

## Tenure-Specific Direction

Tenure should feel like premium enterprise knowledge infrastructure for complex organizations: calm, structured, trustworthy, operational, source-aware, permission-aware, and reviewable.

The visual metaphor is organized working memory, not a generic dashboard.

## Typography

- Use Inter Variable for functional product UI.
- Use Playfair Display only for restricted editorial or formal moments such as report covers, executive summaries, high-impact empty states, and knowledge article hero moments.
- Use Geist Mono for IDs, timestamps, version numbers, policy references, source identifiers, audit values, and technical precision.
- Never use serif typography in dense UI such as navigation, tables, filters, forms, badges, sidebars, metadata, modals, or audit logs.
- Preserve neutral letter spacing unless Tenure's local design tokens explicitly define a tighter value.

## Visual System

- Keep the interface mostly neutral with restrained blue-slate accent usage.
- Use accent color for primary action, active navigation, focus, selected state, key filter, or important linked entity.
- Do not use accent color for decorative icons, random chart fills, card backgrounds, or default AI branding.
- Use canvas, panel, raised, overlay, and sunken surfaces intentionally.
- Use hairline borders and tonal steps before shadows.
- Avoid glassmorphism, heavy shadows, card hover lifts, decorative gradients, purple AI-startup styling, and generic shadcn dashboard output.

## Screen Archetypes

Prefer these Tenure archetypes when relevant:

- dashboard home with one dominant attention region and actionable queues
- organization workspace with coverage, gaps, owners, permissions, and recent changes
- department workspace with SOPs, process coverage, role ownership, and review queue
- SOP or process detail with readable document body and visible metadata rail
- list-first search results with snippets, facets, freshness, source, and access cues
- compact entity directory with right-sheet detail
- audit log or version history with actor, timestamp, object, change, compare, and restore actions
- AI-assisted editor with inline suggestions, diffs, citations, and review states
- settings and permissions grouped by domain with impact and audit context
- formal report or export view with metadata, source list, prepared date, and export controls

## Tenure Data Realism

Use realistic organizational data: departments, owners, SOP titles, source systems, restricted records, review states, freshness states, and uneven counts.

Avoid John Doe, Acme Corp, Department 1, Sample SOP, lorem ipsum, perfect completion, and generic AI marketing copy.
