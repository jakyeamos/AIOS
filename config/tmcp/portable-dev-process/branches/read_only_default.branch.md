# Branch: Read-Only Default

Branch ID: `@branch:read_only_default`

Use this branch when the user asks for analysis, review, triage, planning, discovery, or recommendations without explicitly asking for edits.

Allowed actions: inspect files, run read-only commands, summarize findings, propose changes.

Disallowed by default: editing files, installing dependencies, installing hooks, committing, pushing, deleting, resetting, or writing outside the repo.
