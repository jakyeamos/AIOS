## 4. Deduplication Strategy And Gaps

- Bulk import deduplication is conversation-id based: `get_existing_ids` loads all `ai_history_imports.id` values, each parser builds deterministic ids with `make_id(source, source_id, date, title)`, and the CLI skips conversations whose id already exists. Source: `/Users/jakyeamos/AIOS/bin/import_ai_history.py:54-58`, `/Users/jakyeamos/AIOS/bin/import-ai-history.py:75-77`, `/Users/jakyeamos/AIOS/bin/import-ai-history.py:172-188`.
- Codex cron deduplication is path based: `_get_processed` reads every `processed_files.path`, the main loop checks exact path string membership, and `_mark_processed` inserts only `path` and `processed_at`. Source: `/Users/jakyeamos/AIOS/bin/cron-ingest-codex.py:48-57`, `/Users/jakyeamos/AIOS/bin/cron-ingest-codex.py:192-212`.
- `processed_files` stores no provider id, mtime, file size, content hash, source-native session id, parser version, import status, or failure reason. The schema is only `path` plus `processed_at`. Source: `/Users/jakyeamos/AIOS/bin/migrate-pipeline.py:59-66`.
- Codex cron marks skipped short/invalid sessions as processed, so later content changes at the same path are not reconsidered by the current path-only gate. Source: `/Users/jakyeamos/AIOS/bin/cron-ingest-codex.py:203-212`.
- Path-only dedup misses renamed paths and cannot distinguish changed content at the same path. The code checks only `if path_str in processed` and never compares file content or stat metadata. Source: `/Users/jakyeamos/AIOS/bin/cron-ingest-codex.py:197-201`.
- Bulk import dedup can create a different id for the same source-native conversation when the title or derived date changes, because both are part of the deterministic id input. Source: `/Users/jakyeamos/AIOS/bin/import_ai_history.py:54-58`, `/Users/jakyeamos/AIOS/bin/import_ai_history.py:241-271`, `/Users/jakyeamos/AIOS/bin/import_ai_history.py:509-560`.
- Real-time Claude hooks rely on `session_id` primary-key semantics and idempotent `INSERT OR IGNORE` for SessionStart/tool events, not on file-level transcript dedup. Source: `/Users/jakyeamos/AIOS/schema.sql:19-43`, `/Users/jakyeamos/AIOS/bin/hook-session-start.py:388-470`.
